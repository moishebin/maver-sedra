# Teivah

Read the weekly parsha one word at a time (RSVP), with *shnayim mikra v'echad targum*: each pasuk, section, or the whole parsha twice, followed by Targum Onkelos.

## Features

- This week's parsha and the upcoming ones, on the Israel or diaspora schedule
- Any parsha by link, e.g. `/parsha/noach` or `/parsha/vayakhel-pekudei`
- Reading modes: pasuk by pasuk, section by section (פ / ס), whole parsha, or Torah only
- Adjustable speed, with longer pauses at the end of each pasuk
- Progress saved in the browser per parsha, with a one-click start over
- Keyboard: Space play/pause, ← → jump back/forward, ↑ ↓ speed, Esc back

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```

No API keys or environment variables are needed; all data comes from public APIs.

## How it works

- **Parsha schedule** from [Hebcal](https://www.hebcal.com/home/developer-apis) (`lib/hebcal.ts`).
- **Aliyot, Hebrew names and verse counts** for all 54 parshiot (plus combined ones) live in `lib/parshiot.ts`, generated by `node scripts/generate-parshiot.mjs` from Hebcal and Sefaria.
- **Torah text and Targum Onkelos** from the [Sefaria API](https://developers.sefaria.org/) (`lib/sefaria.ts`), cleaned of footnotes, ketiv/qere duplicates and section markers.
- **Reading sequence** for each mode is built in `lib/reading.ts`; the RSVP timing is in `hooks/useRSVP.ts`.
- API responses are cached in `localStorage` (`lib/cache.ts`), and reading progress is saved there too (`lib/progress.ts`).
